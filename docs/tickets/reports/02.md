## Limits and next action

Qualification is restricted to this exact Linux x86-64 host profile and initial
token subsets. Other builds/platforms and broader SQL require their own audit and
fixtures. Native parser acceptance does not establish object existence, privileges,
serial value correctness or any other server semantic. The separately supplied
host runtime is not a portable distributed binary bundle. Only the current host
Python 3.14 interpreters were exercised; the package syntax targets Python 3.10+.

Process separation does not provide an OS sandbox. Abrupt kill/crash/cancellation
can leave the worker's private 0700 temporary prefix; normal shutdown removes it.
No existing /tmp directories or unrelated processes were swept. The build emitted
the existing setuptools warning about project.license's TOML-table spelling;
shared packaging owns that future compatibility update.
