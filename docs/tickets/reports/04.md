## Shared adapter interface

Import `SchemaSnapshot`, `load_snapshot`, and `refresh_snapshot` from
`cubrid_language.schema`. `SchemaSnapshot` is frozen and contains `schema`,
`availability`, and `stale`. An adapter passes `schema` to pure completion and
surfaces `availability` when present.

```python
from cubrid_language import complete
from cubrid_language.schema import load_snapshot, refresh_snapshot

state = load_snapshot(snapshot_path)
completion = complete(text, cursor, profile, state.schema)
state = refresh_snapshot(snapshot_path, state)
```

The caller supplies the resolved path and owns the returned state. Ticket 03 resolves
configured relative paths against the configuration directory. The loader performs
no configuration discovery, path expansion, database access, or background watching.
A refresh command or configuration event explicitly calls `refresh_snapshot`.
A failed path change retains the previous valid metadata with the stale message;
`None` deliberately disables metadata and returns a fresh unavailable state.
